# Whisper 字幕修正与分集标题 (srts_whisper_large-v3)

本目录的 `srts_whisper_large-v3/` 是用 OpenAI Whisper large-v3 模型生成的 AI 语音识别字幕（非官方）。相对 SenseVoice 版（`srts/`），Whisper 的句意更完整、语气更齐整，但存在**专有名词系统性误识别**。本次工作对 Whisper 字幕做了针对性文本修正，并为 608 集逐一加上简短标题写入文件名。

## 2. 分集标题（写入文件名）

命名格式：`第NNN集_标题.srt`，标题取自《明朝那些事儿》epub 对应章节名（去掉「第X章」前缀）；同一章跨多集时，在该集标题后加**序号** `(n)`（按集号顺序，不带斜杠、不带总数）。

例如：
- `第001集_童年.srt`
- `第017集_洪都的奇迹(1).srt`（洪都的奇迹 第 1 集）
- `第054集_胡惟庸案件(10).srt`（胡惟庸案件 第 10 集，共 11 集）
- `第552集_龙争虎斗(5).srt`
- `第608集_致命的疏漏(3).srt`

标题来源方法（脚本：`gen_titles.py`，输出：`episode_titles.json`）：
1. 从 epub 提取各章正文与标题（共 159 个内容章节）。
2. 用 5-gram 字符重叠 + **单调 DP**（保证集号—章节顺序单调递增）将 608 集逐集映射到最匹配的章节。
3. 取章节名作为该集标题；同章多集按顺序加序号 `(n)`。

```powershell
python gen_titles.py      # 重新生成 episode_titles.json
```

> 局限：仍是 AI 自动识别字幕，非人工官方校对；专有名词已大幅修正，但偶发的断句不当/漏句仍难以完全避免，仅供学习参考。
